## Softwares Tech

We're a DevOps and software engineering company based in Jaipur, India. We build delivery pipelines, run cloud infrastructure, and maintain the applications that sit on top of it — and we hand everything over documented, so your team owns it.

**What we work on**

- **CI/CD** — GitHub Actions, GitLab CI, Jenkins, Azure DevOps
- **Containers & Kubernetes** — Docker, EKS, AKS, Helm
- **Infrastructure as Code** — Terraform on AWS and Azure
- **Monitoring** — Prometheus, Grafana, Alertmanager
- **Software** — web applications, APIs and long-term maintenance

### Open-source starters

| Repository | What it is |
| --- | --- |
| [cicd-pipeline-templates](https://github.com/softwarestech/cicd-pipeline-templates) | Starter pipelines for GitHub Actions, GitLab CI and Jenkins — Docker builds, Terraform plan/apply with AWS OIDC, Kubernetes deploys with approvals |
| [monitoring-stack](https://github.com/softwarestech/monitoring-stack) | Prometheus + Grafana + Alertmanager in one `docker compose up`, with a provisioned dashboard and alert rules |

Both are MIT-licensed and checked on every push. Issues and pull requests are welcome.
